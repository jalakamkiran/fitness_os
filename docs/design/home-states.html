Today instrument stack

Fixed composition: sleep → totals → body HR (≤1 spark) → today’s session cards. Pairing/sync stays supporting chrome. Supersedes the 2026-07-25 swim-only takeaway + absolute no-graphs Home lock.

Review this HTML before Flutter. Stack order and chrome × day matrix are the product lock for this cut. Spec: docs/brainstorms/2026-09-12-home-today-instrument-requirements.md
  • Still off Home: hypnogram, workout charts, history calendars, diagnosis lists, reasoner settings, food/meals, composite readiness/strain scores.
  • Allowed once: one tiny today-HR spark when ≥2 samples exist; otherwise numbers only.
  • Sessions: all sports today, tappable into existing detail; load / TE / recovery as plain numbers when present — omit when absent.
